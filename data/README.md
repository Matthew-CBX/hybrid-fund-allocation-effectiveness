# Data availability

This repository separates demonstration inputs from real analytical outputs.

- `sample/` contains artificial data for two fictional funds. It exists only to demonstrate the annualized-return code path and does not represent any real fund or company.
- `results/` contains real derived analytical outputs for the documented observation period. Company names and published metrics are retained.

The licensed Choice exports, raw fund NAV, raw portfolio positions, raw benchmark downloads, and reconstructable fund-quarter panels are intentionally not distributed. Reproducing the full industry results requires authorized source data matching the definitions in [`docs/data-dictionary.md`](../docs/data-dictionary.md).

The published results are research outputs under a specific methodology and sample policy. They are not investment recommendations.
