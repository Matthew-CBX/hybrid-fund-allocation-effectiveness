# 混合基金资产配置有效性分析

`hybrid-fund-allocation-effectiveness` 是一个可审计的基金数据分析项目：它把市场涨跌造成的仓位自然漂移与基金经理主动调仓分开，检验中国混合基金的股债配置调整是否在下一季度创造了可验证的价值。

> 观察区间、样本筛选和结论均有明确边界。本项目用于研究和作品展示，不构成基金公司综合实力评价、投资建议或未来收益预测。

## 核心结论

核心收益观察期为 **2023Q1—2026Q1**。样本包含 376 只动态配置混合基金和 101 家基金公司，其中 269 只基金进入正式年化、332 只基金进入正式主动配置贡献、16 家公司进入正式评价。

| 指标 | 结果 | 解读 |
|---|---:|---|
| 基金实际年化收益中位数 | 4.5669% | 269 只正式年化基金的几何复利结果 |
| 三资产基准年化收益中位数 | 4.7879% | 使用相同基金、相同季度集合 |
| 相对三资产基准年化超额中位数 | -0.5253% | 正式基金整体未显示正超额 |
| 主动配置年化贡献中位数 | -0.0149% | 主动股债切换增益接近零且略为负 |
| 年化超额为正 | 125/269（46.47%） | 正值比例未过半 |
| 主动配置贡献为正 | 160/332（48.19%） | 正值比例同样未过半 |

现有公司可信度分布为 **A级 0 家、B级 8 家、C级 8 家、观察池 85 家**。因此，当前样本不支持“行业整体存在显著、稳定的主动股债配置增益”。

## 研究问题

混合基金总收益还会受到选股、债券选择、风格和行业暴露、费用、现金、申赎以及其他未建模因素影响。只看总收益，或者只与沪深300比较，容易把这些因素误当成资产配置能力。

本项目把问题收窄为：

1. 扣除股债市场涨跌造成的仓位自然漂移后，基金是否真的主动调整了股票权重？
2. 这次调整在下一季度的股票—债券相对市场中是否方向正确、贡献为正？
3. 汇总到基金公司后，结果是否满足样本量、稳定性和产品集中度要求？

## 分析流程

```mermaid
flowchart LR
    A[授权原始数据\n未公开] --> B[份额合并与数据清洗]
    B --> C[筛选真正动态配置基金]
    C --> D[匹配下一季度基金收益]
    D --> E[构造同类、股票、债券与三资产基准]
    E --> F[扣除仓位自然漂移]
    F --> G[计算调仓命中与主动配置贡献]
    G --> H[基金层年化]
    H --> I[公司层汇总与可信度分级]
    I --> J[阈值、极端值、集中度和审计]
    J --> K[CSV结果与Excel报告]
```

项目使用 2023Q1—2026Q2 的 14 个配置季度筛选动态基金；收益分析需要下一季度数据，因此核心收益观察期截至 2026Q1。

## 样本门槛

| 用途 | 门槛 |
|---|---|
| 动态配置基金 | 至少 8 个可用季度；股票仓位区间 ≥20 个百分点；债券仓位区间 ≥15 个百分点；相邻季度股票/债券最大变动的平均值 ≥5 个百分点 |
| 正式年化基金 | 至少 8 个统一收益可比季度，基金与全部基准使用同一季度集合 |
| 正式主动配置贡献基金 | 至少 8 个漂移可比季度；绝对主动调仓不足 5% 的可比季度贡献记为 0 |
| 正式评价公司 | 至少 30 次 5% 主阈值切换、5 只有效基金、30 条收益观察，且最大单基金观察占比 ≤50% |
| 三资产超额 | 股票、债券和银行存款覆盖率处于 80%—120%（含边界） |

未通过门槛表示证据不足，不代表基金或公司表现较差。

## 四类比较基准

- **同类基准**：同季度、同投资风格的其他基金收益中位数，并剔除基金自身，避免“自己成为自己的基准”。
- **沪深300**：股票市场代理，用于衡量权益市场方向。
- **中债—综合财富（总值）指数**：债券市场财富指数代理。
- **动态三资产基准**：按基金当期股票、债券、银行存款权重组合股票和债券收益；现金端暂以 0 收益代理。

三资产基准比单独使用沪深300更适合混合基金，但仍不是完整收益归因，因为它没有拆分港股、可转债、久期、信用、衍生品、费用和证券选择。

## 两个最重要的指标

### 相对三资产基准年化超额

每只基金先在同一个可比季度集合中，分别计算基金实际收益和三资产基准收益的几何年化，再做差：

```text
基金年化超额 = 基金实际年化收益 − 三资产基准年化收益
```

它仍包含选股和其他未建模影响，因此不能单独证明资产配置能力。

### 主动配置贡献

先计算“如果基金经理什么都不做，股票权重会随股债市场如何自然漂移”，再从实际股票权重中扣除这个被动结果：

```text
主动调仓 = 实际归一化股票权重 − 被动漂移股票权重
主动配置贡献 = 主动调仓 × 下一季度（股票收益 − 债券收益）
```

正值表示调仓方向与下一季度的股债相对表现一致，负值表示方向相反。详细公式见[方法说明](docs/methodology.md)。

## 快速运行

要求 Python 3.11 或更高版本。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
PYTHONPATH=src python -m pytest -q
```

运行合成数据演示：

```bash
PYTHONPATH=src python -m hybrid_fund_allocation.demo \
  --input data/sample/fund_quarter_demo.csv \
  --output data/sample/demo_fund_annualized_result.csv
```

该演示只证明核心年化逻辑能够运行，不会复现真实行业结果。完整真实分析需要自行准备符合[数据字典](docs/data-dictionary.md)的授权输入。

## 测试与审计

- 原始分析基线包含 60 项自动化测试。
- 公开结果由精确行数、字段顺序、主键和审计状态测试锁定。
- 增强分析包含 17 项原始计算审计，公开结果全部通过。
- 最终工作簿包含 11 张工作表、3 个图表、11 项内置检查，并通过公式错误扫描。
- 发布检查会扫描本机路径、密钥模式、超大文件和 Git 历史中的禁止路径。

## 数据边界

公开内容包括真实公司名称、基金名称、衍生指标、排名、稳健性结果和最终报告。以下内容不公开：

- Choice 原始导出；
- 原始基金净值、资产市值、份额净资产和原始季度仓位；
- 原始指数下载；
- 可反推出原始记录的逐期生产底表；
- 本机路径、缓存、运行时依赖和原项目 Git 历史。

## 局限

- 观察期约 3.25 年，且未覆盖全部历史已清盘基金，可能存在存续偏差。
- 沪深300为价格指数，中债为财富指数，与基金复权净值的回报口径并不完全一致。
- 现金收益采用 0 收益代理。
- 尚未纳入基金经理变更、真实披露日、申赎分红、港股、可转债、债券久期和信用暴露。
- 历史统计相关性不能证明因果，也不能保证未来持续。

更多边界见[方法说明](docs/methodology.md)和[NOTICE](NOTICE.md)。
