# 研究结论

## 适用范围

以下结论只适用于 2023Q1—2026Q1 的核心收益观察期、当前动态基金筛选规则和当前基准口径。配置筛选使用 2023Q1—2026Q2 的 14 个季度。

## 样本事实

- 动态配置混合基金：376 只。
- 正式年化基金：269 只。
- 正式主动配置贡献基金：332 只。
- 基金公司：101 家。
- 正式评价公司：16 家。
- A/B/C/观察池：0/8/8/85 家。

## 行业层结论

正式年化基金的实际年化收益中位数为 4.5669%，三资产基准年化收益中位数为 4.7879%。每只基金在同一季度集合上计算后，相对三资产基准年化超额中位数为 -0.5253%。

正式年化基金中，125/269（46.47%）取得正的三资产年化超额。正式贡献基金中，160/332（48.19%）取得正的主动配置年化贡献，整体中位数为 -0.0149%。

因此，更稳妥的结论是：当前样本没有显示行业整体存在显著、稳定的主动股债配置增益。不能把这一结论扩展为“所有混合基金都没有配置能力”，也不能据此判断未来表现。

该指标更接近资产配置动作本身，但仍应结合 bootstrap 区间、Wilson 下限、阈值稳定性和产品集中度。正值不等于长期稳定能力。

## 不应得出的结论

- 不能把正式排名称为基金公司综合实力排名。
- 不能用基金总年化收益证明资产配置能力。
- 不能把观察池公司解释为能力较差；观察池表示证据不足。
- 不能把历史正贡献外推为未来超额。
- 不能把统计相关性解释为基金经理调仓导致的因果效果。

## 后续改进

1. 使用股票全收益指数和真实现金/回购基准统一回报口径。
2. 引入基金经理变更、真实披露日、申赎和分红信息。
3. 加入港股、可转债、债券久期和信用暴露。
4. 延长观察期，增加滚动窗口、样本外和排名迁移检验。
5. 将极端收益事件与基金公告逐笔核验。
